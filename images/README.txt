把图片放进这个目录，然后双击 tools\update-gallery.cmd 重新生成 images.json 和
heatmap.json（右侧热力图的数据）。

目录层级 = 网站层级（只有两级）：

    images/2026/9月/001.jpg
           └大类┘└图集┘

    第 1 层  大类      网站首页的封面卡（只有一个大类时自动进入）
    第 2 层  图集      网站上的图集封面卡，每个图集一张封面；
                      图集里面的图片拼成一面正方形缩略图墙

就这两层。图集里面**不用再分子文件夹**（没有角色、没有草稿箱）：
9月 里的图全部平铺在一起，谁先谁后按文件名排。
真在 9月 里又建了子文件夹也不会出错 —— 里面的图会被合并进 9月，
脚本会打印一行提示告诉你合并了几张。

特殊规则：

  · 想给图集换封面，在这个图集文件夹里放一张
        images/2026/9月/cover.jpg
    （也支持 cover.png / _cover.* / 封面.*）
    这个文件不会被当成图片显示。不放的话就用该图集的第一张图。

  · 想加新的大类，直接在 images/ 下建文件夹即可：
        images/2027/1月/a.jpg

  · 图片直接扔在 images/2026/ 下面（没有图集子文件夹）
    -> 自动归到图集「未分类」。
  · 图片直接扔在 images/ 下面 -> 大类「未分类」/ 图集「未分类」。

文件夹名随便改，改完重跑一次脚本即可。

支持的格式：jpg / jpeg / png / gif / webp / avif / bmp / svg
（PureRef 的 .pur 文件不是图片，会被忽略）


---------------- 网页上长什么样 ----------------

图集里是**固定大小的正方形缩略图**，无缝拼在一起（4 列，窄屏 3 列 / 2 列）。
缩略图是按正方形裁的，所以墙上看到的是中间那块；
**鼠标悬停（或键盘聚焦）才会浮出文件名**，点一下开灯箱看完整原图，
灯箱里还能「下载原图」「复制图片 URL」。


---------------- 每张图的「日期」和右侧热力图 ----------------

热力图按天统计，每张图归到哪一天，按这个顺序决定（先找到先用）：

    1. images/meta.json 里这张图的 "date" 字段（最准，推荐手动写）
    2. 图片自带的 EXIF 拍摄时间（DateTimeOriginal / DateTime）
    3. 上一次生成的 images.json 里记着的日期（换电脑重新生成也不会乱）
    4. 文件修改时间（最后兜底）

所以：手机拍的照片 / 带 EXIF 的图不用管；截图、板绘导出图这类没有 EXIF 的，
如果文件时间是乱的，就在 meta.json 里写死日期：

    {
      "images": {
        "2026/9月/001.jpg": { "title": "9月速写 01", "date": "2026-09-01" }
      }
    }

某天「画了但没导出图片」也想留个记录，就编辑仓库根目录的 daily.json：

    {
      "days": {
        "2026-09-05": 3,                                  // 直接覆盖成 3 张
        "2026-09-06": { "add": 2 },                       // 在自动统计之上再加 2
        "2026-09-07": { "count": 1, "note": "只发了一张" },  // 覆盖 + 备注
        "2026-09-08": { "note": "写了一天代码" }            // 只留备注，数量按自动算
      }
    }

改完重跑一次 tools\update-gallery.cmd，热力图就更新了。

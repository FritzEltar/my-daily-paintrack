把图片放进这个目录，然后双击 tools\update-gallery.cmd 重新生成 images.json 和
heatmap.json（右侧热力图的数据）。

目录层级 = 网站层级（三级）：

    images/全部/大图集1/角色1/001.jpg
           └大类┘└大图集┘└角色┘

    第 1 层  大类      网站首页的封面卡（只有一个大类时自动进入）
    第 2 层  大图集    网站上的图集封面卡，每个图集一张封面
    第 3 层  角色      图集内的页签（没有「全部」这一档）

特殊规则：

  · 图片直接放在图集文件夹下（没有角色子文件夹）
        images/全部/大图集1/还没分类.png
    会自动归入「草稿箱」，排在角色页签最后一位。

  · 想给图集换封面，在这个图集文件夹里放一张
        images/全部/大图集1/cover.jpg
    （也支持 cover.png / _cover.* / 封面.*）
    这个文件不会被当成图片显示。不放的话就用该图集的第一张图。

  · 第 4 层及更深会合并进角色名：
        images/全部/大图集1/角色1/服装/a.jpg  ->  角色「角色1/服装」

  · 想加新的大类，直接在 images/ 下建文件夹即可：
        images/新大类/图集A/角色1/a.jpg

文件夹名随便改，改完重跑一次脚本即可。

支持的格式：jpg / jpeg / png / gif / webp / avif / bmp / svg
（PureRef 的 .pur 文件不是图片，会被忽略）


---------------- 每张图的「日期」和右侧热力图 ----------------

热力图按天统计，每张图归到哪一天，按这个顺序决定（先找到先用）：

    1. images/meta.json 里这张图的 "date" 字段（最准，推荐手动写）
    2. 图片自带的 EXIF 拍摄时间（DateTimeOriginal / DateTime）
    3. 上一次生成的 images.json 里记着的日期（换电脑重新生成也不会乱）
    4. 文件修改时间（最后兜底）

所以：手机拍的照片 / 带 EXIF 的图不用管；截图、板绘导出图这类没有 EXIF 的，
如果文件时间是乱的，就在 meta.json 里写死日期：

    {
      "images": {
        "全部/大图集1/角色1/001.jpg": { "title": "速写 001", "date": "2026-01-05" }
      }
    }

某天「画了但没导出图片」也想留个记录，就编辑仓库根目录的 daily.json：

    {
      "days": {
        "2026-01-05": 3,                                  // 直接覆盖成 3 张
        "2026-01-06": { "add": 2 },                       // 在自动统计之上再加 2
        "2026-01-07": { "count": 1, "note": "只发了一张" },  // 覆盖 + 备注
        "2026-01-08": { "note": "写了一天代码" }            // 只留备注，数量按自动算
      }
    }

改完重跑一次 tools\update-gallery.cmd，热力图就更新了。
